## Projekt herunterladen

So kannst du dieses Projekt auf deinen eigenen Computer kopieren:

```bash
git clone https://github.com/naoufelmankai/mein-erstes-Projekt.git
cd mein-erstes-Projekt
```

## Wichtige Git-Befehle

| Befehl | Was er macht |
| --- | --- |
| `git status` | Zeigt, welche Dateien geändert wurden |
| `git add <datei>` | Merkt eine Änderung für den nächsten Commit vor |
| `git commit -m "Nachricht"` | Speichert die Änderungen mit einer Beschreibung |
| `git push` | Lädt deine Commits zu GitHub hoch |
| `git pull` | Holt die neuesten Änderungen von GitHub |
| `git checkout -b <name>` | Erstellt einen neuen Branch und wechselt dorthin |
